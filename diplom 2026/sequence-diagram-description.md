# Описание диаграммы последовательности

Диаграмма последовательности отображает порядок взаимодействия компонентов симуляционной среды в рамках одного полного цикла обработки транспортной единицы. Участниками взаимодействия выступают: оператор, симуляционный цикл, три очереди (главная полоса и две дополнительные), два агента и координирующий модуль маршрутизации.

## Поступление автомобиля

Цикл начинается с проверки временного условия подачи: если с момента предыдущего поступления истёк интервал, определяемый параметром задержки, симуляционный цикл добавляет новую транспортную единицу в очередь главной полосы. Добавление выполняется только при наличии свободного места — в противном случае элемент отбрасывается, моделируя эффект насыщения дорожного участка.

## Формирование сигналов агентов

После обновления главной полосы симуляционный цикл запрашивает у каждого из двух агентов бинарный сигнал готовности к приёму автомобиля. Первый агент получает решение от оператора-эксперта, который устанавливает значение на основании наблюдаемого состояния среды. Второй агент вычисляет решение автоматически: сравнивает текущую длину собственной очереди с пороговым значением и сообщает о готовности, если порог не превышен.

## Маршрутизация

При выполнении временного условия перевода симуляционный цикл передаёт пару сигналов координирующему модулю. Модуль определяет целевую полосу по детерминированной таблице: при взаимной неготовности агентов автомобиль остаётся в главной полосе; при взаимной готовности полоса выбирается случайно с равной вероятностью; при готовности только одного агента автомобиль направляется на его полосу. После определения цели транспортная единица извлекается из главной очереди и помещается в соответствующую дополнительную.

## Выезд из полос

Завершающая фаза цикла — проверка условий выезда для каждой из двух дополнительных полос. Каждая полоса обладает независимым параметром задержки выезда, определяющим её пропускную способность. При истечении соответствующего интервала головной элемент очереди извлекается, моделируя покидание транспортной единицей дорожной сети.

## Итог

Диаграмма фиксирует четыре последовательных фазы одной итерации симуляционного цикла: поступление, принятие решений агентами, маршрутизация и выезд. Каждая фаза управляется собственным временным параметром, что обеспечивает независимую настройку интенсивности и пропускной способности отдельных участков сети. Асимметрия агентов — ручное управление первого и пороговая стратегия второго — отражена в различном порядке формирования их сигналов.
